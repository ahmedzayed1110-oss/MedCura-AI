# Release security and rights audit

The runnable source, fixed synthetic outputs, cited aggregate derivatives, selected cell index, original generated research assets, and new figures are eligible for the dedicated private repository. Generated deck and workbook ZIP structures are inspected as OOXML. The local binary cap is 15 MB per tracked file. PDF and screenshot review covers generated presentations, pilot templates and synthetic application views.

The original ZIP, source workbooks, supplied PDFs, pasted master contract, full cell/PDF text snapshots, live SQLite stores, credential files, environment files, temporary outputs and backup remain local. The original input licenses and redistribution permissions are unresolved. The release adds no software redistribution license. Use the citation file for attribution and clear downstream reuse with the rights holders.

The release scanner checks filenames, size, common credential formats, absolute user paths, personal-email patterns and patient identifier patterns. The app's standard docs describe password configuration but do not supply a reusable credential. The scanner complements manual review of supported files. CI reports validation on future commits. See the test record for third-party scanner availability.

To recover the prior release, use the unmodified ZIP in the preservation directory. The complete extracted tree sits beside it with a SHA-256 inventory. Never supply clinic or patient records to the demo.
