# Gaps and limitations

- The five baselines use seven one-day origins from a fixed synthetic ledger. Any operational benefit and field forecast validity require an authorized prospective pilot.
- The 2024 facilities are locations, and the 2022 population denominator supports a mixed-year geographic ratio. Site workload and customer counts require separate evidence.
- Native TCP and Docker verification depend on the host. Run the app locally and repeat the genuine TCP test suite when those services are available.
- Source workbook and reference-document redistribution rights remain unresolved. Supply authorized inputs locally using their hashes.
- Private GitHub publication requires working account authentication, collision resolution if applicable, and verification of private settings before push.
