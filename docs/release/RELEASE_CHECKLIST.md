# Release checklist

- Verify all original hashes and ZIP integrity before recovery.
- Review scientific output parity, evidence types, figure crosswalk and both test logs.
- Review the staged-file scan and local-only register.
- Clone or extract the tracked release and verify Python, browser and reproduction commands.
- Authenticate to GitHub. Confirm the owner and that the intended repository name is available.
- Create with explicit private visibility. Verify owner/name and private status before pushing main and the annotated tag.
- Recheck visibility, commit, branch, tag and authenticated file access after push.
